# Висновок до Лабораторної роботи №1

Під час виконання Лабораторної роботи №1 була успішно розроблена модульна програма для Windows, яка демонструє принципи об'єктно-орієнтованого програмування через організацію коду в окремі функціональні модулі (module1.js для введення тексту та module2.js для вибору значення з повзунка), з централізованою обробкою подій у головному скрипті (script.js), при цьому реалізовано два діалогові вікна відповідно до варіантів 0 і 1 (вікно введення тексту та вікно з горизонтальним скролінгом від 1 до 100), що забезпечує зручність використання, модульність коду та його легкість до розширення.
